### Featured projects

**[fontur-backend](https://github.com/SebastianVillegasVelasquez/fontur-backend)**
A production Retrieval-Augmented Generation (RAG) system built for an institutional client, delivered through OBJ Digital. Architecture: LlamaIndex for the data layer, LangGraph for orchestration, and pgvector as the production vector store, with RAGAS and DeepEval used for retrieval/response evaluation.

**[gestion-proyectos](https://github.com/SebastianVillegasVelasquez/gestion-proyectos)**
A full-stack project management platform ("Bitácora") built for an e-learning / IT production company, designed to handle project structures with deep, branching task hierarchies rather than flat to-do lists. Backend: FastAPI, async SQLAlchemy, Alembic, PostgreSQL. Frontend: React 19, Vite, TanStack Query, Tailwind CSS.

**[tabulaML](https://github.com/SebastianVillegasVelasquez/tabulaML)**
A thesis project (Trabajo de Grado, Tecnológico de Antioquia) building a web platform for automated generation and evaluation of Machine Learning models from user-uploaded datasets — an AutoML workflow accessible without writing training code. Backend: FastAPI with Redis as a job queue for model training. Frontend: React. Database: PostgreSQL.
